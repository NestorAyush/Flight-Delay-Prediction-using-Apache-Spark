# Flight-Delay-Prediction-using-Apache-Spark
This project explores flight delay and cancellation prediction using big data tools and machine learning techniques. It is based on the CN6022 module coursework at the University of East London.

## 🚀 Project Overview

The goal is to analyze a large dataset of U.S. domestic flights using **Apache Spark**. It involves:

- Extracting insights using **Spark SQL**
- Building predictive models with **Spark MLlib**

## 📊 Dataset

- **Source**: [Download ZIP](https://tinyurl.com/mwxnxnkb)
- **Main file**: `Combined_Flights_2022.csv` (~1.31GB)
- Includes additional files: `Airlines.csv` and `readme.html`

## 🔧 Tools & Technologies

- Apache Spark (PySpark)
- Spark SQL
- Spark MLlib
- Python
- Jupyter Notebook / Google Colab
- Matplotlib / Seaborn for visualization

## 💡 Key Tasks

1. **Big Data Analysis**
   - Implement complex SQL queries on the dataset
   - Visualize findings with tables and plots

2. **Machine Learning**
   - Build and compare two ML models to predict:
     - Flight cancellation or delay status **or**
     - Delay time
   - Apply full ML pipeline: preprocessing, feature selection, class imbalance handling, evaluation

## 📌 Focus Areas

- Scalability of big data tools
- Model accuracy and interpretability
- Real-world implications of flight delay prediction
